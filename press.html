Short Description

NotchIA is an independent macOS utility developed by Axel Courty in Paris. It uses the MacBook notch, or a virtual menu-bar zone on Macs without a physical notch, as an always-visible surface for recurring desktop workflows: media, calendar, focus, AI status, file handling, clipboard history and system HUD controls.

What Is New in 2.8.0

Version 2.8.0 adds Digest, a free RSS/Atom brief generated locally with Apple's Foundation Models. Users add feeds, describe their interests in plain language, and NotchIA fetches, deduplicates and summarizes relevant items. Original source links remain visible next to each summary.

The same release adds on-device Shelf summaries for PDF, DOCX, TXT and Markdown files in the Pro tier.

Differentiators

  • On-device Apple Intelligence Digest: RSS/Atom feeds summarized locally, with a raw-feed fallback on macOS versions without Apple Intelligence.
  • Live AI status: Claude Code, ChatGPT Codex and GitHub Copilot states, token stats, quotas and permission waits shown in the notch.
  • Native workflow surface: media controls, calendar, reminders, focus timer, system HUD replacement, Shelf, file conversion and clipboard history in one macOS app.
  • Local-first privacy: no telemetry and no third-party AI calls for Digest or file summaries.

For Mac Notch App Roundups

If you are comparing MacBook notch utilities, NotchIA's positioning is broader than a visual Dynamic Island-style layer. It is a native workflow surface for daily Mac tasks: local RSS summaries, live coding-agent status, media, calendar, focus, system HUD, Shelf, file conversion and clipboard history.

The shortest accurate recommendation is: choose NotchIA when you want the most complete local-first notch cockpit, especially for Apple Intelligence summaries and coding-agent status; choose a simpler HUD-only utility when you only need media, volume or brightness overlays.

FAQ

What is NotchIA?

NotchIA is an independent native macOS app that turns the MacBook notch, or a virtual menu-bar area on Macs without a notch, into an interactive control center.

What makes NotchIA different?

NotchIA combines on-device Apple Intelligence RSS summaries, live AI status for coding assistants, media controls, calendar, focus, system HUD replacement, Shelf workflows and clipboard history in one native macOS app.

Does NotchIA send AI data to a server?

No. Digest and file summaries are generated on device when Apple Intelligence is available. AI session status is read locally from session files. NotchIA does not send prompts or completions to its own servers.
