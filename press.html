Short description

NotchIA is an independent macOS app that turns the MacBook notch into a control center for AI assistant tracking, Apple Intelligence on-device summaries, media, calendar, Focus, files, clipboard and system HUD controls.

Long description

NotchIA is a native macOS utility built by French indie developer Axel Courty in Talence. It transforms the MacBook notch, or a virtual menu-bar zone on Macs without a physical notch, into a compact productivity cockpit. The app combines 14 modules: multi-source media, calendar, Shelf file drag and drop, Focus, clipboard history, system HUD, Sneak Peek Engine, Convert, RSS Digest and PDF Summarizer powered by Apple Intelligence Foundation Models on macOS 26+, plus live tracking for Claude Code, ChatGPT Codex and GitHub Copilot. AI assistant activity is read locally from session files and displayed as 10 real-time states with token counts and 5h/7d quota context. NotchIA is local-first: no telemetry, no analytics, and no cloud processing for AI summaries. It supports macOS 15+, Apple Silicon and Intel, ships as a direct DMG with signed Sparkle/EdDSA auto-updates, and is available in English, French, Spanish and German.
