Questions fréquentes

Que se passe-t-il si j'arrête de payer ?

Quand le paiement sera disponible, les fonctionnalités Pro (Claude Code et Codex) pourront être arrêtées à tout moment. Le reste de NotchIA continuera de marcher normalement.

Sur combien de Mac puis-je l'installer ?

Le forfait mensuel est prévu pour 1 Mac. La licence à vie est prévue pour 2 Mac.

Le lifetime inclut-il les futures versions majeures ?

Oui. Toutes les mises à jour de NotchIA, y compris les versions majeures, sont incluses pour les acheteurs lifetime.
