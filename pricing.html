Questions fréquentes

Que se passe-t-il si j'arrête de payer ?

Les fonctionnalités Pro (Claude Code et Codex) deviennent inaccessibles. Le reste de NotchIA continue de marcher normalement (média, calendrier, étagère). Tu peux toujours réactiver plus tard.

Sur combien de Mac puis-je l'installer ?

3 Mac par licence. Si tu en changes un, contacte le support pour libérer un slot.

Le lifetime inclut-il les futures versions majeures ?

Oui. Toutes les mises à jour de NotchIA, y compris les versions majeures, sont incluses pour les acheteurs lifetime.

J'ai perdu ma clé de licence. Que faire ?

Va sur /account, entre l'email d'achat — on te renvoie une nouvelle clé. L'ancienne est invalidée pour ta sécurité.

Paiement sécurisé Stripe. TVA appliquée selon ton pays. Remboursable 14 jours sans condition.
