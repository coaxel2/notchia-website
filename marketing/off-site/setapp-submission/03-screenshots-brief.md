# Screenshots brief — Setapp submission

## Delivery format

- **Master resolution:** 2880 x 1800 px (Retina @2x), PNG, sRGB, < 5 MB each
- **Downscale also delivered:** 1920 x 1200 px @1x
- **Optional widescreen variant:** 3840 x 2160 px for Setapp homepage feature slots
- **Filename convention:** `notchia-setapp-NN-slug@2x.png` (e.g. `notchia-setapp-01-hero@2x.png`)
- **Color profile:** Display P3 if shooting on Apple Silicon, else sRGB
- **No animated formats** for the main pack. Optional: 1 short MP4 (10 s, no audio, H.264, < 8 MB) for the trailer slot.

## Apple Marketing Guidelines to respect

- Do **not** put the Apple logo in any composition.
- Do **not** use "Apple", "Mac" or "macOS" inside the NotchIA product name overlay.
- Use the official MacBook frame from Apple's Marketing Resources if a device frame is needed (always current generation).
- Wallpaper inside frames must be a generic neutral background or a license-cleared abstract; no copyrighted artwork, no third-party brand wallpapers.
- Status bar in screenshots: hide battery % and SSID, use a neutral time (9:41 is Apple's convention but optional here — `13:37` works too).
- App icons of other vendors (Spotify, Claude, Slack, Figma) may appear inside UI only if the workflow being demonstrated genuinely uses them and they're not the visual subject.
