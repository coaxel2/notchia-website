Notes de version · 2.9.26

Silky Seal : une encoche qui s'ouvre vraiment

Par NotchIA · 17 octobre 2026 · 3 min de lecture

Jusqu'ici, l'encoche apparaissait d'un coup, déjà à sa taille finale. La 2.9.26 l'anime : elle s'agrandit depuis l'encoche matérielle et se referme en douceur. Cette version ramène aussi en un clic la fenêtre où travaille votre agent IA, et corrige plusieurs défauts de suivi des sessions Codex et Claude Code.

Une ouverture animée

L'encoche s'agrandit désormais depuis l'encoche matérielle, portée par un ressort avec un léger dépassement en fin de course, puis se résorbe sans rebond à la fermeture. Le contenu arrive un souffle après le début du mouvement, en fondu, et s'efface avant que l'encoche ne se referme.

Si « Réduire les animations » est activé dans les réglages d'accessibilité de macOS, l'encoche passe par un simple fondu, sans ressort.

Un clic pour retrouver l'agent Pro

  • Un clic sur la cellule Codex de l'encoche fermée amène au premier plan la fenêtre où Codex travaille : terminal, VS Code ou l'app ChatGPT.
  • Dans l'onglet IA, un bouton « Afficher » suivi du nom de l'app fait de même, pour Claude comme pour Codex.
  • Dans Terminal et iTerm2, c'est l'onglet exact qui est sélectionné.
  • Les points de session Claude d'une session lancée dans un terminal mènent maintenant à ce terminal.

Codex : plus de session fantôme

Un Codex interrompu juste après le début d'un tour laissait l'encoche afficher « Codex travaille », avec un chrono qui pouvait courir pendant des heures. L'encoche vérifie maintenant qu'un process Codex existe encore, et qu'il était déjà lancé au début du tour. Sinon, le tour est refermé.

Claude Code : des sessions mieux détectées

  • Seuls les process Claude qui ont un terminal de contrôle comptent comme des sessions. Ceux lancés par des outils annexes, comme un observateur de mémoire ou le pont d'une extension de navigateur, n'apparaissent plus comme des sessions en plus.
  • Avec Claude Code 2.1.300 et suivants, les copies de requêtes présentes dans le transcript ne relancent plus le chrono et ne remettent plus les compteurs du tour à zéro.
  • Échap pendant une réponse termine bien le tour, /compact n'en ouvre plus, et une fin de tour libère les outils encore en attente : « Permission » ne reste plus affiché une fois le tour fini.

Questions fréquentes

L'encoche peut-elle s'ouvrir sans effet de ressort ?

Oui. Si « Réduire les animations » est activé dans les réglages d'accessibilité de macOS, l'encoche passe par un simple fondu, sans ressort.

L'encoche affichait « Codex travaille » pendant des heures : est-ce corrigé ?

Oui. Quand Codex était interrompu juste après le début d'un tour, la session restait ouverte avec un chrono qui continuait de tourner. Depuis la 2.9.26, l'encoche vérifie qu'un process Codex existe encore et qu'il était déjà lancé au début du tour. Sinon, le tour est refermé.

Quelles fenêtres le clic ramène-t-il au premier plan ?

La fenêtre où travaille l'agent : le terminal, VS Code ou l'app ChatGPT. Dans Terminal et iTerm2, l'onglet exact est sélectionné. Le clic fonctionne sur la cellule Codex de l'encoche fermée, sur les points de session Claude d'une session lancée dans un terminal, et via le bouton « Afficher » de l'onglet IA, pour Claude comme pour Codex.

Comment l'obtenir

Déjà utilisateur ? L'auto-update Sparkle vous propose la 2.9.26 automatiquement. Pour forcer : menu NotchIA → Vérifier les mises à jour.

Nouvel utilisateur ? brew install --cask coaxel2/notchia/notchia, ou le .dmg depuis la page d'installation.
