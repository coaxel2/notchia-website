Counting Crow : le % de contexte IA affiche enfin la vraie valeur

Par NotchIA · 18 juillet 2026 · 3 min de lecture

Deux mises à jour publiées le 17 juillet 2026, toutes deux consacrées à la fiabilité de l'onglet IA : la 2.9.8 « Patient Eagle » apprend aux notifications à attendre la vraie fin du travail des agents, et la 2.9.9 « Counting Crow » corrige le pourcentage de contexte Claude Code — le chiffre le plus regardé de l'encoche.

Un % de contexte enfin juste

Si tu utilises Claude Code avec une session à grande fenêtre (1 million de tokens), NotchIA calculait jusqu'ici le pourcentage sur une fenêtre supposée de 200k — résultat : une pastille bloquée à 100 % en rouge alors que ta session avait encore une marge énorme. Depuis la 2.9.9 :

  • le % de contexte vient directement de la source officielle de Claude Code — les fenêtres 1M sont correctement reconnues ;
  • la taille de fenêtre de chaque session est mémorisée : le % reste juste même en jonglant entre plusieurs sessions ;
  • les tokens de la requête en cours et la taille de fenêtre affichés dans les stats sont alignés sur les mêmes sources.

Des notifications qui attendent la vraie fin

La 2.9.8 règle un agacement classique : quand Claude Code lance des tâches en arrière-plan (agents, commandes longues), la notification « terminé » partait trop tôt, en plein milieu d'une tâche qui continuait toute seule. NotchIA attend désormais la fin réelle du travail — une seule notification, au bon moment.

Le reste des corrections

Apple Music — l'état de lecture est mis à jour sur le thread principal : pochette et infos de piste plus fiables.

Shelf — un échec de compression ZIP ne laisse plus de copies orphelines dans le dossier temporaire.

Diagnostic — un échec de création du rapport est détecté proprement au lieu d'ouvrir un fichier inexistant dans le Finder.

Nouvel utilisateur ? Télécharge NotchIA (~12 Mo) depuis la page d'accueil. Musique, Calendrier, Digest et Concentration sont gratuits à vie ; le suivi IA est dans le pack Pro — voir les tarifs.

FAQ

Pourquoi le % de contexte Claude Code était-il faux avant la 2.9.9 ?

NotchIA calculait le pourcentage sur une fenêtre supposée de 200k tokens. Les sessions Claude Code à grande fenêtre (1 million de tokens) étaient donc affichées à 100 % en rouge alors qu'elles avaient encore de la marge. Depuis la 2.9.9, la valeur vient directement de la source officielle de Claude Code et la taille de fenêtre de chaque session est mémorisée.

Qu'est-ce qui change pour les notifications en 2.9.8 ?

Quand Claude Code lance des tâches en arrière-plan (agents, commandes longues), NotchIA attend désormais la vraie fin du travail avant d'envoyer la notification « terminé ». Plus de notification prématurée en plein milieu d'une tâche qui continue toute seule.

Comment obtenir NotchIA 2.9.9 ?

Les utilisateurs existants reçoivent la mise à jour via l'auto-update Sparkle (menu NotchIA → Vérifier les mises à jour). Les nouveaux utilisateurs téléchargent le DMG (~12 Mo) depuis notchia.app/install. NotchIA nécessite macOS 15.0+ (Apple Silicon ou Intel).
