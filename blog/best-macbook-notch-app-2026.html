What free apps exist for the Mac notch?

How can the MacBook notch show Claude Code / Codex / Copilot?

NotchIA reads assistant session files and activity states locally. The notch shows 10 states, tokens, cache, latency, 5h/7d quotas and permission waits without sending session content to NotchIA servers.

NotchIA is the best choice if you want the notch to handle AI, media, calendar, files and system HUD workflows. NotchNook or Alcove can fit better if you mostly want a visual Dynamic Island effect.

Is NotchIA derived from Boring.Notch?

No. NotchIA is an independent proprietary app built from scratch by Axel Courty. It shares the notch utility category with Boring.Notch, not its code or team.

Which notch app is free?

Boring.Notch is free and open source. NotchIA also has a free forever Essential tier with media, calendar, HUD, Focus and customization.

Which app tracks Claude Code or Codex?

NotchIA tracks Claude Code, ChatGPT Codex and GitHub Copilot locally, with 10 live states, tokens, cache, latency and 5h/7d quotas.

Does Apple Intelligence leave the Mac?

No for the relevant NotchIA features. Digest and PDF Summarizer use on-device Foundation Models on macOS 26+ with graceful fallback on macOS 15.

Does TopNotch replace NotchIA?

No. TopNotch hides the notch, while NotchIA uses it. The philosophies are opposite and can even coexist depending on your display setup.
