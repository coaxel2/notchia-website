Apps Mac essentielles pour développeurs en 2026

Par Axel Courty · 27 mai 2026 · 12 min de lecture · macOS 14+

Réponse courte. En 2026, la stack dev Mac qui change vraiment ta journée tient en 15 apps réparties sur 5 catégories : IDE (Cursor, Zed, Xcode 26), terminaux (Warp, Ghostty, iTerm2), agents IA (Claude Code, ChatGPT Codex, GitHub Copilot), productivité (Raycast, Rectangle, CleanShot X), cockpit / monitoring (NotchIA, Stats, Tailscale). Sélection honnête, dev-to-dev, sans bullshit marketing.

La stack 2026 dev Mac en une phrase

Un IDE AI-first (Cursor ou Zed), un terminal moderne (Warp ou Ghostty), au moins un agent IA en CLI (Claude Code et/ou Codex), un launcher (Raycast), et un cockpit pour voir tout ce qui tourne en arrière-plan (NotchIA). Le reste est du confort.

Pourquoi cette sélection ?

J'utilise ces apps quotidiennement depuis au moins six mois, dans des contextes pro (Notch IA en SaaS indie, plusieurs side projects open-source) et avec des stacks variées (Swift/SwiftUI sur Xcode 26, TypeScript/Next.js, Python/FastAPI, Rust). Mes critères :

  • Efficacité quotidienne : est-ce que je la lance tous les jours ? Si non, dehors.
  • Indie-friendly : pas de seat licensing entreprise minimum, paiement raisonnable, achat à vie quand possible.
  • Prix raisonnable : gratuit > one-shot > abonnement faible. Toute app à plus de 20 $/mois doit vraiment se justifier.
  • Maturité 2026 : pas de vapor, pas de bêta instable. Les apps citées ont toutes au moins une release publique stable.

Pas de NotchIA biais (c'est mon app, je sais) : elle est citée pour ce qu'elle apporte de spécifique au workflow IA, et seulement à ce titre.

Éditeurs / IDE (3 apps)

Catégorie 1 · Édition de code

L'IDE est le centre de gravité du dev. En 2026, le choix se résume à trois grandes options sur Mac.

#1 · Éditeurs

IDE AI-first · Anysphere · cursor.com

Cursor

Hobby gratuit · Pro 20 $/mois · Business 40 $/mois

Cursor est un fork de VS Code avec agent IA natif (Composer, Agent mode), edits multi-fichiers, mémoire de contexte projet, complétion Tab sur stéroïdes. Très utilisé chez les devs full-stack web depuis 2024. La version 2026 a stabilisé le mode Agent pour les tâches longues. Mêmes raccourcis que VS Code, mêmes extensions, donc bascule indolore.

Limite : c'est un VS Code modifié, donc même empreinte mémoire (~ 600 Mo au repos). Pour les très gros monorepos, Zed est nettement plus léger.

Éditeur natif Rust · Zed Industries · zed.dev

Zed

Gratuit (perso) · Pro IA 20 $/mois

Zed est l'éditeur des anciens d'Atom (Nathan Sobo and co), écrit en Rust, rendu GPU, multiplayer en temps réel. Démarrage en moins d'une seconde, latence frame-perfect, IA intégrée (Claude, GPT, Gemini au choix). Idéal pour Rust, Go, TypeScript. Le mode collaboratif (channels, share project) est unique sur le marché.

Limite : écosystème d'extensions encore plus jeune que VS Code/Cursor. Si tu vis dans des extensions exotiques (Markdown All in One, GitLens, etc.), tu vas devoir te désintoxiquer.

IDE Apple · developer.apple.com

Xcode 26

Gratuit (avec compte Apple Developer)

Xcode 26 est obligatoire pour tout ce qui touche à Swift, SwiftUI, iOS, macOS, watchOS, visionOS. Version 2026 intègre Predictive Code Completion (modèle Apple Intelligence local) et un assistant Swift Assist (cloud). Le simulateur iOS a enfin gagné en rapidité. Reste lourd (~ 15 Go d'install avec les plateformes) mais incontournable pour le natif Apple.

Astuce : pour le code Swift en dehors du contexte App Store, Cursor + extension Swift fonctionne très bien et te dispense de lancer Xcode pour les snippets rapides.

Terminaux & shell (3 apps)

Catégorie 2 · Terminal

Le terminal n'est plus juste un terminal en 2026 — c'est l'endroit où tournent les agents IA. Trois choix sérieux.

Terminal IA · Warp · warp.dev

Warp

Gratuit · Pro 15 $/mois (teams)

Warp a inventé les command blocks : chaque commande et son output forment un bloc isolé qu'on peut copier, réutiliser, partager. Couplé à Warp AI (suggestion de commandes, explication d'erreurs), c'est le terminal qui pense le plus comme un dev de 2026. Natif Apple Silicon, démarre en ~ 200 ms.

Limite : nécessite un compte Warp (gratuit) pour les fonctions IA. Certains devs préfèrent rester anonymes — auquel cas Ghostty.

Terminal natif Zig · ghostty.org

Ghostty

Gratuit (open-source, MIT)

Ghostty est le terminal écrit par Mitchell Hashimoto (co-fondateur HashiCorp) en Zig. Rendu GPU, conformité xterm complète, config en HCL, démarrage instantané. Sorti stable fin 2024, version 2026 ajoute le multiplexage natif. Si tu veux la pure performance sans IA cloud, c'est le choix.

Référence historique · iterm2.com

iTerm2

Gratuit (open-source)

iTerm2 reste la référence depuis 15 ans. Tiling, splits horizontaux/verticaux, profils, instant replay, recherche dans l'historique, triggers, tmux integration. Moins flashy que Warp, plus mature que Ghostty. Pour des sessions Claude Code longues sur plusieurs projets en parallèle, son système de profils et de hotkey window reste imbattable.

Assistants IA en local / sur Mac (3 apps)

Catégorie 3 · Agents IA

L'écart entre dev avec et sans IA est devenu absurde en 2026. La vraie question n'est plus « est-ce que j'utilise une IA ? » mais « laquelle, pour quoi ? ».

Agent CLI · Anthropic · anthropic.com/claude-code

Claude Code

Inclus dans Claude Pro 20 $/mois · Max à partir de 100 $/mois

Claude Code est l'agent CLI d'Anthropic. Tu lances claude dans un dossier, il lit le code, exécute des commandes, modifie des fichiers, lance des tests, lance des sous-agents. Excellent en raisonnement long, en refactoring, en debug complexe. La sortie Claude Sonnet 4.7 (janvier 2026) a encore élargi la fenêtre de contexte.

Limite : quota 5h et hebdomadaire sur Pro — d'où l'intérêt d'un cockpit qui te montre où tu en es (voir NotchIA plus bas).

Agent CLI · OpenAI · openai.com/codex

ChatGPT Codex

Inclus dans ChatGPT Plus 20 $/mois

Codex est la réponse OpenAI à Claude Code. Lancé fin 2024 avec son propre CLI, il s'intègre directement à ton compte ChatGPT. Plus rapide sur les tâches courtes/répétitives, excellent en code review, parfois meilleur que Claude en SQL et en Python data. Beaucoup de devs combinent les deux selon la tâche.

Assistant in-editor · GitHub · github.com/features/copilot

GitHub Copilot

Individual 10 $/mois · Pro 19 $/mois · Business 19 $/mois

GitHub Copilot vit dans ton éditeur (VS Code, JetBrains, Xcode via extension officielle depuis 2024). Toujours imbattable pour les complétions inline rapides au fil du clavier. La version 2026 utilise GPT-5 et Claude 4.7 au choix dans le mode Chat. Souvent oubliée à tort dans les comparatifs : pour la productivité ligne-à-ligne, ça reste la meilleure UX.

Productivité dev (3 apps)

Catégorie 4 · Productivité

Launcher · raycast.com

Raycast

Gratuit · Pro 8 $/mois

Raycast remplace Spotlight. ⌘ Space, tape ce que tu veux : ouvrir un projet, lancer un script, killer un port, regarder un PR GitHub, traduire, calculer, exécuter un snippet. Le store d'extensions a explosé : Linear, Notion, GitHub, AWS, Docker, k9s, plus de 1500 extensions officielles. Raycast Pro ajoute un LLM intégré (Claude / GPT au choix), utile en complément de Claude Code pour les micro-tâches.

Window manager · rectangleapp.com

Rectangle

Gratuit (Rectangle Pro à 10 $ one-shot)

Rectangle manage tes fenêtres au clavier : ⌃⌥← pour moitié gauche, ⌃⌥↑ plein écran, etc. Open-source, configurable, zéro friction. macOS 15 a enfin ajouté son propre window snapping, mais Rectangle reste plus puissant (presets custom, halves/thirds/sixths, multi-écrans).

Captures + enregistrement · cleanshot.com

CleanShot X

29 $ one-shot · Cloud 8 $/mois optionnel

CleanShot X est ce qui transforme tes captures d'écran en documentation propre : annotations, blur, redaction des secrets, scroll capture, MP4 et GIF, OCR sur capture. Indispensable dès que tu écris une PR description, un bug report, un guide interne. Coûte un peu mais 0 % d'abonnement obligatoire — c'est rare en 2026.

Cockpit / monitoring (3 apps)

Catégorie 5 · Cockpit

La vraie nouveauté 2025-2026 : les agents IA tournent en tâche de fond pendant que tu fais autre chose. Il te faut une vue dédiée. Trois apps complémentaires.

#13 · Cockpit IA

Encoche en cockpit IA · indie français · notchia.app

NotchIA

Essentiel gratuit · Pro 2,99 €/mois ou 24,99 € à vie

NotchIA transforme l'encoche du MacBook (ou la barre de menus sur Mac sans encoche) en cockpit IA en direct. Quand Claude Code, ChatGPT Codex ou GitHub Copilot tourne en arrière-plan, NotchIA détecte automatiquement la session et affiche son état parmi 10 reconnus : Compilation, Terminal, Recherche, Lecture, Modification, Web, Écriture, Sous-agent, Planification, Exécution.

Bonus : stats jetons (input, output, cache hit, cache create) en temps réel, quotas 5 h et 7 j avec barre de progression, notifications quand l'agent attend une permission, indicateur multi-session (points colorés sous l'encoche fermée pour les sessions parallèles), bring-to-front de l'IDE en un clic. Ajoute aussi l'Apple Intelligence Digest (résumé de notifications, batterie, météo) pour les Mac compatibles. Lecture 100 % locale depuis ~/.claude/projects/ et équivalents — aucune donnée ne quitte le Mac.

Version actuelle : v2.8.0 « Wise Owl » sortie le 15 mai 2026.

System monitor · open-source · github.com/exelban/stats

Stats

Gratuit (open-source, MIT)

Stats affiche dans la barre de menus : CPU (par cœur P/E sur Apple Silicon), GPU, RAM, swap, réseau (up/down en temps réel), disques, capteurs, batterie, ventilateurs. Hyper-configurable, zéro pub, zéro télémétrie. La version 2026 supporte les nouveaux SoC M5 et M5 Pro.

VPN mesh WireGuard · tailscale.com

Tailscale

Personal gratuit (3 utilisateurs, 100 devices) · Pro 6 $/utilisateur/mois

Tailscale crée un VPN mesh WireGuard entre tes machines (Mac, Linux, iPhone, NAS, serveurs). Tu accèdes à ton localhost depuis ton téléphone, tu partages un dev server à un collègue sans ngrok, tu connectes ta CI à une machine on-prem. SSH sans clé via Tailscale SSH. Indispensable dès que tu bosses en multi-machine.

Workflows : 3 stacks types selon profil

Stack 1 — Full-stack web (TypeScript / Next.js / Postgres)

Cursor (IDE) + Warp (terminal IA) + Claude Code (agent long) + GitHub Copilot (complétions inline) + Raycast (launcher) + NotchIA (cockpit) + Rectangle + Tailscale (partage de localhost à un designer).

Coût : ~ 53 $/mois (Cursor 20 + Claude Pro 20 + Copilot 10 + Raycast Pro 8 = 58 $) ou ~ 45 $ si tu skip Raycast Pro.

Stack 2 — iOS / macOS natif (Swift / SwiftUI)

Xcode 26 (obligatoire) + Cursor ou Zed (édition rapide hors-Xcode) + iTerm2 (gérable avec Xcode) + Claude Code (refactor Swift) + NotchIA (utile pour Xcode 26 : tu vois la compilation tourner depuis l'encoche pendant que tu fais autre chose) + CleanShot X (screenshots App Store).

Coût : ~ 22 $/mois (Claude Pro 20 + Raycast Pro 8 optionnel). Le natif Apple est encore une des stacks les moins chères en 2026.

Stack 3 — Indie SaaS solo (Rust / Go / Python)

Zed (perf Rust/Go) + Ghostty (terminal pur) + Claude Code + ChatGPT Codex (alternance selon tâche) + Raycast + NotchIA (visualiser les deux agents en parallèle) + Stats (surveiller ses propres workers) + Tailscale (preview à des beta testeurs).

Coût : ~ 40 $/mois (Claude Pro 20 + ChatGPT Plus 20). Le combo deux-agents est devenu standard chez les indies parce que les quotas Claude (5h / 7j) deviennent vite serrés en mode autonome — Codex prend le relais.

FAQ

Quel est l'IDE le plus utilisé par les développeurs Mac en 2026 ?

VS Code reste l'IDE le plus utilisé, mais Cursor (fork VS Code avec IA agentique native) a gagné énormément de terrain depuis 2024. Zed monte chez les devs sensibles à la performance native (Rust). Xcode 26 reste obligatoire pour iOS/macOS natif.

Cursor ou Zed : lequel choisir ?

Cursor est plus mature côté IA (agent intégré, edits multi-fichiers, mémoire de contexte). Zed est plus rapide nativement (rendu GPU, Rust) et plus léger en RAM, avec une IA intégrée plus discrète. Cursor si l'IA est au centre du workflow, Zed si la performance et la collaboration en temps réel le sont.

Faut-il payer Claude Code et ChatGPT Codex en parallèle ?

Pas obligatoire. Claude Code (Claude Pro 20 $/mois ou Max) reste leader sur les tâches longues et le raisonnement. Codex (ChatGPT Plus 20 $/mois) est bon en exécution rapide et intégration OpenAI. Beaucoup de devs combinent les deux pour 40 $/mois, en utilisant NotchIA pour voir leurs états en parallèle et alterner selon la tâche.

Quelle app pour surveiller les agents IA sur Mac ?

NotchIA est la seule app macOS qui détecte automatiquement Claude Code, ChatGPT Codex et GitHub Copilot et affiche leurs 10 états en direct dans l'encoche du MacBook (Compilation, Recherche, Modification, Web, Sous-agent, etc.), avec stats jetons/cache/quotas 5h et 7j. 100 % local. Essentiel gratuit, Pro 2,99 €/mois ou 24,99 € à vie.

Quel terminal choisir entre Warp, Ghostty et iTerm2 ?

Warp pour les blocks de commande et l'IA intégrée, Ghostty pour la pure performance (GPU, écrit en Zig), iTerm2 pour la robustesse et la configurabilité historique. Aucun n'est mauvais — c'est une question de préférence et d'écosystème.
